# Glossary

Vocabulary this repo runs on. Use these terms as defined; don't drift to synonyms.

## LAPMAN

**L**ittle **A**s **P**ossible, **M**uch **A**s **N**ecessary.

The reporting budget for agent output: minimum tokens, full meaning. No padding, no pleasantries, no unrequested explanation — and no omission either. "As little as possible" is bounded below by "as much as necessary": if a fact changes a decision, it ships; if not, it doesn't.

Applies to reports, summaries, commit messages, docs, and answers.
